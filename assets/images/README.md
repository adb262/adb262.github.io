# Writing thumbnails

Square placeholder SVGs live here. Replace them with real images (JPG/PNG recommended, ~400x400px or larger) when you're ready.

| File                       | Article                                                       |
| -------------------------- | ------------------------------------------------------------- |
| `world-models.svg`         | Unlabelled Gameplay as Pretraining for World Models           |
| `underspecification.svg`   | The Inherent Underspecification of Natural Language           |
| `adaptive-llms.svg`        | Adaptive LLMs for Medical Question Answering via Evolution    |
| `quantile-flows.svg`       | Autoregressive Quantile Flows for Predictive Uncertainty Est. |

To swap in a real image, either:

1. Replace the file in place keeping the same name (and `.svg` extension is fine for vector art), or
2. Add a new file (e.g. `world-models.jpg`) and update the corresponding `<img src="...">` in `index.html`.
